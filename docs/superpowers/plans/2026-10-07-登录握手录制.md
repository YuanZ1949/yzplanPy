# 登录握手与认证失败录制实施计划（层 D 补完）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让层 D 的录制回放覆盖**登录握手**与**认证失败**：接缝开在 `TelnetSession` 内部、握手/失败以显式 `kind` 步落盘（口令脱敏）、`ReplaySession` 能消费握手段并确定性地复现认证失败，同时**不破坏既有夹具与既有 `consumed`/`remaining` 数字语义**。

**Architecture:** 三处协同——`telnet.TelnetSession` 新增零默认开销的 `set_exchange_hook()` 旁路接缝，`_login` 是唯一上报点；`recorder.RecordingSession` 在 `open()` 时装 hook，把握手段与命令步一起脱敏落盘；`replay.ReplaySession` 的 `open(username, password)` 先消费握手里段（只收不发的回包步「消费不比对」），命令步游标与严格匹配语义不变，握手消费另记 `login_consumed`。

**Tech Stack:** Python 3.11 · pytest · 纯 stdlib（`json`/`re`/`os`/`logging`/`socket`）；不 import Qt；不引入新依赖。

**Spec:** `docs/superpowers/specs/2026-10-07-登录握手录制-design.md`（唯一实现依据；本计划与它的偏差已在文末专节列明）。

## Global Constraints

- **纯 stdlib、无 Qt**：`modules/router_admin/{telnet,replay,recorder}.py` 不得 import PySide6/Qt。
- **TDD**：每个 Task 先写失败测试 → 看到失败 → 最小实现 → 看到通过 → 提交（conventional commits：`test:`/`feat:`/`docs:`）。
- **顶层无副作用**（`AGENTS.md` 测试规范 1）：测试文件 import 时不得建 QApplication、写环境变量、读写文件/DB。
- **脱敏是硬要求**（spec §4.2/§5.4）：任何 step 的任何字段都不得出现明文口令；`password_sent` 位 `send` 恒为 `***`。
- **旁路铁律**（spec §5.3）：hook 抛出的任何异常都必须被吞；`set_exchange_hook` 默认 `None` 时登录路径零行为变化。
- **既有数字语义不变**（spec §6.3）：`consumed`/`remaining` 只统计**命令步**，`consumed==0/1/3`、`remaining==0/2` 等既有断言数字保持不变；握手另记 `login_consumed`。
- **命令步严格匹配不变**（spec §6.2）：`_LOGIN_KINDS` 里只收不发的回包步是唯一放宽点，命令步失配仍 `AssertionError`。

## Review Focus

spec 隐含、但若不刻意覆盖最可能咬到人的五类输入/失败模式（每类都在下面指定 Task 里有一条测试钉住）：

1. **hook 抛异常** → 登录流程必须完全不受影响（旁路铁律）；`set_exchange_hook` 未调用时行为零变化。→ Task 3。
2. **v1 录制（步里无 `kind`）** → 加载后 `login_consumed==0`、`consumed`/`remaining` 与旧语义逐字一致、命令步照常匹配。→ Task 1（格式默认）+ Task 2（回放）。
3. **非法输入**：未知 `kind`、`version ∈ {0, 3, 99, "1", None, True}` → 加载期 `ValueError`，不能带着半个会话跑到断言里。→ Task 1。
4. **认证失败** → 不再落成 `steps: []` 空文件，且回放确定性抛 `TelnetLoginError`（消息含「口令」，只锁类型与阶段，不锁路由器文案）。→ Task 2（回放）+ Task 3（落盘）。
5. **握手里的明文口令** → 落盘后 `password_sent.send == "***"`，且 `send`/`recv` 双侧都不得残留明文。→ Task 3 + Task 5（真夹具）。

```python
    def open(self, username=None, password=None) -> None:
        self._opened = True
        self._closed = False
        self._index = 0
        self._login_consumed = 0
        self._cmd_consumed = 0
        while (self._index < len(self._steps)
               and self._steps[self._index]["kind"] in _LOGIN_KINDS):
            step = self._steps[self._index]
            kind = step["kind"]
            if kind == "username_sent" and username is not None \
                    and not _matches(step["send"], username):
                raise AssertionError(
                    f"登录握段用户名与录制不匹配（第 {self._index + 1} 步）："
                    f"录制={step['send']!r} 实际={username!r}")
            if kind == "password_sent" and password is not None \
                    and not _matches(step["send"], password):
                raise AssertionError(
                    f"登录握段口令与录制不匹配（第 {self._index + 1} 步）")
            self._index += 1
            self._login_consumed += 1
            if kind == "login_error":
                raise TelnetLoginError("认证失败：路由器拒绝了该口令")
```

```python
"""登录握手录制与认证失败落盘（纯数据、无 Qt）。

用最小脚本化 socket 驱动真实 TelnetSession._login，验证接缝 set_exchange_hook
在成功/失败两条路径上的上报序列，以及 RecordingSession 的落盘与脱敏。
"""
import json
import socket
from collections import deque

import pytest

from modules.router_admin import telnet as t
from modules.router_admin.recorder import RecordingSession


class _ScriptedSocket:
    """按 recv 顺序吐预置响应块的最小 socket；无回显、无 IAC。"""

    def __init__(self, chunks):
        self._chunks = deque(chunks)
        self.sent = bytearray()
        self.closed = False

    def settimeout(self, value):
        pass

    def setsockopt(self, *a):
        pass

    def connect(self, addr):
        pass

    def sendall(self, data):
        self.sent.extend(data)

    def recv(self, n):
        if not self._chunks:
            raise socket.timeout("fake: 脚本已耗尽")
        return self._chunks.popleft()

    def close(self):
        self.closed = True


def _login_session(chunks, **kw):
    fake = _ScriptedSocket(chunks)
    opts = {"user": "root", "password": "s3cr3t", "socket_factory": lambda: fake}
    opts.update(kw)
    return t.TelnetSession("192.0.2.1", **opts)


_SUCCESS = [b"XiaoQiang login: ", b"Password: ", b"root@XiaoQiang:~# "]
_FAIL = [b"XiaoQiang login: ", b"Password: ", b"Login incorrect\r\n"]

    s = _login_session(_SUCCESS)
    s.set_exchange_hook(events.append)
    s.open()
    assert [e["kind"] for e in events] == [
        "login_prompt", "username_sent", "password_prompt",
        "password_sent", "login_ok"]
    assert events[0]["recv"].endswith("login: ")
    assert events[1]["send"] == "root"
    assert events[3]["send"] == "s3cr3t"          # 原样上报；脱敏在录制侧完成


def test_未装hook_登录行为零变化():

    assert s.connected is True

        raise RuntimeError("录制坏了")

    s = _login_session(_SUCCESS)
    s.set_exchange_hook(boom)

    assert s.connected is True


def test_认证失败_抛TelnetLoginError且上报login_error():
```
